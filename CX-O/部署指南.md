## ⏳ 需要你手动完成的步骤

### 步骤 1: 下载 GLM-4V-9B-Flash 模型

**方法 A: 使用 PowerShell 脚本（推荐）**

打开 PowerShell，运行：
```powershell
cd c:\CX-O\CX-O
& "C:\ProgramData\anaconda3\python.exe" "download_glm4v_model.py"
```

**方法 B: 使用 Python 直接下载**

```powershell
& "C:\ProgramData\anaconda3\python.exe" -c "
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id='THUDM/glm-4v-9b-flash',
    local_dir='C:\\CX-O\\CX-O\\models\\THUDM\\glm-4v-9b-flash'
)
"
```

**方法 C: 使用 HuggingFace CLI**

```bash
# 安装 huggingface_hub
pip install huggingface_hub

# 下载模型
huggingface-cli download THUDM/glm-4v-9b-flash --local-dir C:\CX-O\CX-O\models\THUDM\glm-4v-9b-flash
```

**预计时间**: 10-30 分钟（模型约 8GB）

---

### 步骤 2: 验证模型下载完成

检查模型文件是否存在：
```powershell
Test-Path "C:\CX-O\CX-O\models\THUDM\glm-4v-9b-flash\config.json"
```

应该返回 `True`

---

### 步骤 3: 启动 vLLM (Docker)

确保 Docker Desktop 已启动，然后运行：

```powershell
cd c:\CX-O\CX-O
docker compose -f vllm-docker-compose.yml up -d
```

**验证 vLLM 启动**:
```powershell
docker ps | findstr cx-o-vllm
curl http://localhost:8000/health
```

---

### 步骤 4: 安装 CX-O 后端依赖

```powershell
cd c:\CX-O\CX-O
& "C:\ProgramData\anaconda3\Scripts\conda.exe" install -n cx-o -c conda-forge -y librosa soundfile jieba pypinyin
```

---

### 步骤 5: 启动 CX-O 所有服务

**方法 A: 使用启动脚本**
```powershell
cd c:\CX-O\CX-O
.\1-1.start-all.bat
```

**方法 B: 手动启动各服务**

1. **启动 CXHMS Backend (端口 8000)**:
```powershell
cd CXHMS
& "C:\ProgramData\anaconda3\envs\cx-o\python.exe" -m uvicorn backend.api.app:app --host 0.0.0.0 --port 8000
```

2. **启动 SenseVoice ASR (端口 8001)**:
```powershell
cd SenseVoice
& "C:\ProgramData\anaconda3\envs\cx-o\python.exe" api.py
```

3. **启动 F5-TTS (端口 8002)**:
```powershell
cd F5-TTS
& "C:\ProgramData\anaconda3\envs\cx-o\python.exe" webapi.py
```

4. **启动 Gateway (端口 8100)**:
```powershell
cd cx-o-gateway
& "C:\ProgramData\anaconda3\envs\cx-o\python.exe" main.py
```

5. **启动前端**:
```powershell
cd cx-o-frontend
npm run dev
```

## 🔧 故障排查

### 模型下载失败
- 检查网络连接
- 尝试使用镜像站：`https://hf-mirror.com`
- 使用 VPN

### Docker 启动失败
- 确保 Docker Desktop 已启动
- 检查 NVIDIA Docker 支持：`docker run --gpus all nvidia/cuda:12.1-base-ubuntu22.04 nvidia-smi`

### 端口冲突
- 检查端口占用：`netstat -ano | findstr :8000`
- 修改配置文件中的端口
