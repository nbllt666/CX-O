三档防火墙

直播弹幕内容审核与决策系统，规则过滤 + LLM 智能决策的混合架构

  • 第一档 block：违规内容直接拦截
  • 第二档 passive：正常弹幕通过不回复
  • 第三档 reply：优质弹幕互动回复
  • LLM 不可用时默认放行，避免误伤
Firewall BlacklistFilter LLMDecision

记忆衰减公式 — 双阶段指数衰减模型

T(t) = a · e-k1·dt + (1-a) · e-k2·dt

a 控制短期/长期衰减比例，k1 和 k2 分别为短期和长期衰减速率
重要性分数 ≥ 0.95 的记忆为永久记忆，永不衰减

  • 音效插入：[effect:name] 标记自动插入音效
  • 流式合成：按句分割，逐句返回

语音工作站 — 五步工作流

Step 1

参考音频生成 (VoxCPM)

三种模式：Voice Design（文本到语音）、Controllable Clone（参考音+控制）、Ultimate Clone（音频克隆）

Step 2

情感参考音频生成 (CosyVoice)

8 种情感参考 + 56 种过渡参考 = 64 个参考音频，Instruct2 模式生成

Step 3

训练数据准备 (So-VITS-SVC)

音频切片、语音标注、特征提取，为模型训练准备数据集

Step 4

模型训练 (So-VITS-SVC + F5-TTS)

可配置 epochs/batch_size/lr，异步训练任务，同时支持 F5-TTS 微调

Step 5

推理 (So-VITS-SVC + IndexTTS 2)

音色转换推理，IndexTTS 2 支持 8 情感 x 5 强度 = 40 组合，按需启停节省 GPU

Quick Start

快速开始

最小化部署仅需 Python 3.11+、Node.js 18+ 和 Ollama

Windows 一键启动

# 一键启动所有服务 start-all.bat

手动启动

# 1. 启动后端服务 cd CX-O-SERVER set PYTHONPATH=%CD%\.. python -m server.main # 2. 新终端：启动前端 cd CX-O-Frontend npm install npm run dev

访问界面

  • 前端界面：http://127.0.0.1:5173
  • API 文档：http://127.0.0.1:8000/docs
  • 健康检查：http://127.0.0.1:8000/health

环境要求

  • Windows 10/11 或 Linux
  • Python 3.11+
  • Node.js 18+
  • CUDA 11.8+ (GPU 支持，可选)
  • Ollama + 模型 (如 qwen3:latest)
