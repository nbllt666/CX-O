💬 对话系统

这是整个系统的核心——你和 AI 角色互动的主阵地。从打字聊天到实时语音通话，从文字到图片，全都能搞定。

基础

文字对话

流式逐字输出，AI 回复时能看到思考过程、工具调用过程。支持 Markdown 渲染，代码块有语法高亮。

  • 多消息类型：正文、思考链、工具调用、工具结果、外部事件
  • 上下文管理：清空、追加、手动/自动总结
  • 闹钟功能：AI 可以设闹钟，到点弹窗提醒
多模态

图片对话

上传图片让 AI 看图说话。支持多张图片同时上传，AI 能理解图片内容并做出回应。

  • 可配置单次最大图片数量
  • 图片与文字混合输入
  • 视觉理解能力（依赖多模态模型）
语音输入

语音转文字

按住说话，松开后自动识别成文字填入输入框。不用打字，直接说话就行。

  • 录音后发送给后端 ASR 服务识别
  • 识别结果附带语种、情绪、事件检测
  • 支持笑声、掌声、咳嗽等非语言事件识别
语音输出

文字转语音

AI 的回复自动转成语音播放，播放时虚拟形象口型同步。支持情感语音和音效插入。

  • 流式合成：4 字即切片送合成，首包延迟低
  • 情感语音：不同情绪用不同参考音色
  • 音效标签：文本中插入标签即可触发音效
  • 参考音频克隆：用参考音频定制音色
连续对话

语音对话模式

开启后进入连续对话模式，AI 说完自动重新开始录音，不用反复按按钮。

核心亮点

双流式实时语音

这是整个语音系统最厉害的部分——全双工实时通话，就像跟真人打电话一样。边听边说，还能互相插话。

  • 边听边说：ASR 实时出字幕，LLM 边想边说，TTS 边收边播
  • 你打断 AI：你一开口就立刻停掉 AI 的播放，不用等她说完，毫秒级响应
  • AI 打断你：AI 会在你说话时判断要不要插话，时机一到就停掉自己、直接插一句回应
  • 插话有分寸：CONTINUE/IGNORE/INTERRUPT 三态判定，你还没说完或只是自言自语时，AI 不会抢话
  • 投机预填充：你说出两个字就启动 AI 思考，省下约 500ms
  • 首包延迟控制在 300ms 以内
  • 听声辨人：认得每个和你说话的人，谁在场说话一眼看清
  • CosyVoice 主引擎：带参考音频克隆、情感表达，失败自动降级到备用 TTS
听声辨人

记住我的声音

聊天时对它说一句「记住我的声音，我叫 XX」，它就把你的声纹存下来。之后在语音对话、圆桌会议里，谁在说话一眼就能看出来，不用猜。

  • 语音建档：出声一句就能注册，同一会话里立即生效
  • 识别不卡嘴：声音刚算出来时先标记「识别中」，随即更新成说话人名字，全程不拖慢对话
  • 多人场景一条条认：会议、直播间里说话的人各自有名字，不会张冠李戴

TTS 智能降级

语音合成以 CosyVoice 为主引擎（支持克隆与情感表达），主引擎不可用时自动降级到备用 TTS，保证对话不中断。无需手动切换。

🎭 虚拟形象系统

Live2D 和 VRM 双引擎，让你的 AI 角色活起来——会笑、会生气、会歪头看你，说话时口型同步，风吹过来头发会飘。

Live2D

Live2D 引擎

加载标准的 Live2D Cubism 模型（.model3.json），支持全套表情和动作系统。

  • 音频分析驱动的口型同步
  • 表情混合（expressionMix）
  • 动作播放（motion trigger）
  • 待机动画（呼吸、身体摆动、眼睛眨动）
  • 参数覆盖（精细控制每个参数）
VRM

VRM 引擎

加载 VRM 3D 模型（.vrm），基于 Three.js 渲染，支持完整的 3D 骨骼动画。

  • 口型同步 + 元音分析
  • 表情系统（BlendShape）+ 插值平滑过渡（表情自然渐变，不再"啪"地切换）
  • 多组骨骼控制：肩/手/脚/眼/指等 26 组可控骨骼，能表达指物、耸肩、转眼、竖拇指等细腻动作
  • 骨骼动作自动归中：设定保持时长后自动回到待机（也可保持不归中）
  • 视线策略：桌宠跟随鼠标、直播读弹幕时看向弹幕区
  • 动作交叉淡入：模型动画片段流畅切换（如挥手），带动交互风
  • 风场系统：头发衣物物理飘动 + 交互风力
  • 空闲微表情、眼球追踪、双频率摇摆
  • 音画同步：表情/动作随 AI 朗读逐步触发，读到哪句就做对应表情
  • 性能自适应：低帧时自动削减待机开销，保持流畅
  • 模型自选：加载默认 CX-OPEN.vrm，或用系统对话框选本地 .vrm
统一接口

双引擎统一抽象

两种引擎通过统一接口管理，切换时无需改代码。工厂模式自动根据类型创建对应驱动。

  • 统一能力：表情、口型、动作、舞台变换、水印
  • 快捷情绪按钮：开心/生气/悲伤/惊讶/放松/中性
  • 底部交互面板：实时显示当前表情及权重
  • 形象类型选择器：无 / Live2D / VRM 三选一
标签驱动

对话内嵌标签驱动

AI 回复中可以内嵌特殊标签，自动驱动虚拟形象做对应的表情和动作。让纸片人随对话内容做出反应。

  • 表情标签 + BlendShape 标签：触发表情并平滑过渡
  • 骨骼标签：驱动受控骨骼转动，到点自动归中
  • 动作标签：触发模型动画片段交叉淡入（如挥手）
  • 姿势标签 / 风场标签 / 停顿标签
  • 音画同步：随 AI 朗读逐步触发，读到对应句子做对应表情/动作
动画调节

动画参数面板

在设置中可以精细调节虚拟形象的动画参数，找到最自然的呈现效果。

  • 摇摆幅度/频率/不规则度
  • 呼吸幅度/频率/不规则度
  • 头部空闲漂移范围
  • 空闲微表情强度
  • 头部跟踪限位
  • 眼球跟踪开关
  • 自动保存 / 手动保存配置

🧠 记忆系统

AI 会记住你们之间发生过的事。三层记忆 + 向量搜索 + 知识图谱，聊得越久她越了解你。

三层记忆

短期 / 长期 / 永久

记忆按重要性分三层管理，AI 会自动判断哪些值得记住。

  • 短期记忆：近期对话内容，会随时间淡化
  • 长期记忆：重要信息，定期衰减但不轻易删除
  • 永久记忆：关键信息，永不衰减
  • 重要性达阈值自动转永久
  • 工作记忆 / 情景记忆分类
向量搜索

语义搜索

用向量嵌入做语义搜索，不只是关键词匹配，而是理解意思来找相关记忆。

  • 支持 Weaviate（独立服务或嵌入式）
  • 混合搜索：关键词 + 向量结合
  • 时间轴可视化：按时间分布筛选记忆
  • 向量同步 / 重建 / 索引率统计
知识图谱

图谱可视化

四类图（用户/物品/概念/事件），力导向图展示实体与关系。管理知识就像看一张关系网。

  • 节点与关系可视化（力导向图）
  • 路径查找与关联记忆检索
  • 图数据库基于 SQLite（可选 Weaviate 向量增强）
  • 记忆可与图谱实体联动
自动维护

衰减与去重

记忆不是只增不减，系统会自动维护，保持记忆库干净有效。

  • 自动衰减：每 24 小时跑一轮，老旧低价值记忆弱化
  • 去重：相似度超 0.85 的记忆自动合并
  • 归档：不重要的记忆压缩归档
  • 情感分析：记忆带情感分数
蒸馏提炼

记忆蒸馏

把杂乱的对话信息提炼成结构化记忆。9 个状态机步骤，从预读到交叉验证再到最终存储，每一步都有决策。

  • 单次蒸馏与批量蒸馏两种模式
  • LLM 评估质量分数（可配置模型）
  • 6 个决策点控制流程走向
  • 拒绝机制：低质量内容自动拒绝
日记视图

时间线日记

按日期分组的时间线视图，展示每天的记忆摘要、心情和来源。像翻日记本一样回顾过去。

  • 按日期分组，可展开/折叠
  • 显示标题、心情、来源、消息范围
  • 批量管理：打标签、归档、删除
记忆助手

自然语言管理

专用记忆管理对话页，用自然语言操作记忆库——搜索、更新、删除、导出、统计，说句话就行。

  • 流式回复 + 思考过程折叠展示
  • 工具调用可视化
  • Markdown 渲染（含代码高亮）

👥 多角色管理

创建多个 AI 人格，每个有独立的人设、记忆和属于自己的声音。角色之间还能互相通信，或拉上几位开一场圆桌会议，合作完成任务。

Agent 管理

创建与配置

从零创建专属角色，每个角色都可以独立配置人设和参数。

  • 可配置：名称、描述、系统提示词、模型、温度、最大 Tokens
  • 记忆场景配置：闲聊/任务/首次交互
  • 衰减模型选择
  • 支持编辑、克隆、删除
ACP 协议

角色间通信

Agent Communication Protocol——让多个 AI 角色互相发消息、协作完成任务。

  • 选择目标 Agent 发送/接收消息
  • 自动刷新拉取回复
  • 连接/断开/查看状态
  • 每个 Agent 独立记忆隔离（per-agent collection）
  • 独立图数据库（per-agent SQLite graph）
角色卡

从记忆生成角色

从现有记忆中提取信息，一键生成角色卡，再从角色卡创建新 Agent。让记忆变成新角色的人设基础。

多模型路由

模型分配

每个 Agent 可以指定使用不同的模型，系统会自动路由到对应模型并做健康检查。

  • 主模型（main）：日常对话
  • 摘要模型（summary）：内容总结
  • 记忆模型（memory）：记忆处理
  • 支持 Ollama / vLLM / TRT-LLM 三种接入
专属音色

每个角色各有各的声音

在 Agent 管理里给每个角色单独绑定一段参考音频，她说话、开会、语音通话都用这套声音。

  • 参考音频从语音工作站的音色资产里选
  • 绑定后，该角色所有语音输出都用这份音色
  • 没绑定的角色走全局默认音色
圆桌会议

多 Agent 圆桌会议

把几位角色拉进同一场共享语音会议，你坐主位，点谁谁接话，或抛个话题让大家抢答。

  • 一场会议多位角色同台，共享同一个语音会议房间
  • 点名谁谁接话，或按话题让大家抢答
  • 发言令牌保证同一时刻只有一个人开口，不抢麦、不乱哄哄
  • 整场会议沉淀成记忆，之后还能回忆起来

📺 直播推流

让你的 AI 角色当虚拟主播。直接对接 OBS，弹幕实时互动，四个独立源灵活组合。

直播台

虚拟主播舞台

在一个页面里展示虚拟形象 + 弹幕 + 字幕，WebSocket 实时接收所有内容。

  • 虚拟形象 + 弹幕覆盖 + AI 回复字幕
  • 实时弹幕滚动展示（用户名/内容/颜色）
  • 流式内容带标签驱动形象动作表情
  • VAD 语音活动检测驱动口型
  • 连接状态和在线客户端数显示
OBS 拆分

四源独立输出

把直播画面拆成四个独立透明背景源，在 OBS 里分别添加为浏览器源，灵活排版。

  • 形象源：纯 Live2D/VRM 渲染，透明背景
  • 弹幕源：纯弹幕 overlay，透明背景
  • 字幕源：纯 AI 回复字幕，透明背景
  • 音频源：OBS 专用音频控制面板
  • 推荐设置：1920x1080，添加透明背景 CSS
音频中枢

音频控制面板

直播和对话的音频中枢，管理所有音频输入输出。

  • 麦克风选择 + 实时音量电平条 + 增益调节
  • TTS 音量 + 输出音量控制
  • 回声消除 AEC：自动/浏览器原生/AudioWorklet/手动四种模式
  • WebSocket 同步状态
  • 多客户端在线数显示
  • TTS 播放文本实时显示

🎙️ 语音工作站

专业级声音克隆与训练工作站。从数据集生成到模型训练再到推理输出，完整流程一站搞定。

步骤一

批量数据集生成

用 VoxCPM 批量生成 SVC 训练数据集，为专属音色训练准备素材。

  • 批量生成 SVC 训练数据集
  • 数据可直接导入训练流程
步骤二

So-VITS-SVC 训练

用准备好的数据集训练专属音色模型。完整的数据集管理和训练参数控制。

  • 数据集管理：导入 wav/mp3/flac/ogg/zip
  • 预处理流程
  • 训练参数：epochs / batch size / learning rate
  • 实时进度轮询
  • 模型列表管理
步骤三

So-VITS-SVC 推理

用训练好的模型做变声推理，选好参数就能生成成品。

  • 选择训练好的模型
  • 输入音频变声
  • 变调范围：-12 到 +12 半音
  • 聚类模型可选
  • 生成并试听

🎵 AI 作曲与歌声合成

写个歌谱就能生成带人声的歌曲。旋律编辑、和弦编排、MusicXML 导入，选好声库就能合成。

歌谱编辑

双模式编辑器

表单模式和 JSON 直编模式双向同步，想怎么编就怎么编。

  • 表单模式：标题 / BPM / 拍号 / 调号 / 伴奏风格
  • 旋律轨编辑
  • 和弦轨编辑
  • JSON 直编模式：直接写 JSON
  • 两种模式实时同步
导入

MusicXML 导入

上传 MusicXML 乐谱文件，自动转换填充到编辑器。从现成的乐谱开始改，不用从零写。

校验

实时校验

调用后端校验歌谱，逐条展示错误信息。写错了立刻知道哪里有问题。

合成

歌声合成

选好声库和参数，一键合成带人声的歌曲。实时进度展示，合成完直接播放。

  • voice_bank 声库选择
  • SVC 模型可选（可不变声）
  • 变调参数
  • 人声/伴奏增益调节
  • 任务进度实时轮询 + 步骤展示
  • 歌曲历史：播放/删除成品

🐱 桌面宠物

透明悬浮窗趴在桌面上，鼠标穿透不挡操作，随时拖到屏幕角落。想让几位角色都来作伴？一次能开好几只，把她们全"养"在桌面上陪着你。

悬浮窗

透明窗口

Electron 透明悬浮窗，背景完全透明，只显示虚拟形象。鼠标穿透功能让你点击穿透到下方的窗口。

  • 透明背景 + 鼠标穿透（可开关）
  • 拖拽移动窗口位置
  • 双击返回主窗口
交互

右键菜单

右键调出快捷菜单，常用操作一键直达。

  • 关闭悬浮窗
  • 返回主窗口
  • 窗口置顶切换
  • 麦克风开关
功能

完整对话能力

桌面宠物不只是看，还能聊天和语音对话。上方虚拟形象 + 下方对话区 + 音频控制。

  • PetAvatar 虚拟形象展示
  • PetChat 对话交互
  • PetAudioPanel 音频控制
多开

桌宠多开

给任意角色都开一只桌宠，多只一起趴在桌面上，各绑各的角色，谁跟谁也不打扰谁。

  • 管理页里为任意角色一键开启/关闭对应的桌宠
  • 每只桌宠绑定一个角色，个性、记忆、声音都各自独立
  • 窗口标题带上角色名，录屏/OBS 一眼就能分清是哪一位

数十个工具

  • 插件列表查看
  • CXFC 本机插件发现（自动发现并以技能形式调用）
  • 直连：后端直接访问插件服务（默认方式）
  • 前端转接：插件通过 APP 前端中转接入，适合后端无法直连插件的场景
  • 后端嵌入式：插件直接跑在后端进程内，不走网络，适合本机轻量工具
屏幕感知

让 AI 看见你的屏幕

可选开启后，AI 能通过你的屏幕或摄像头"看见"你正在做的事，并据此回应。默认关闭，想开才开。

  • 两种模式：看图模式省资源，录像模式会记住你经历的过程
  • 记住过程——你玩了两小时黑神话、debug 卡住又解决，她都记在心里，改天聊起还能回忆
  • 看图模式会自动调节节奏：画面动得勤就看得勤、静止就放慢，省流量不打扰
  • 设置页一键开关，录像模式单独开关，关闭后立即停发画面
电脑控制

让 AI 帮你操作电脑

桌面宠物以插件形式把本机控制能力授权给 AI——看屏幕、按键、运行程序，AI 能直接动手帮你办事。

  • 屏幕控制、键盘控制、运行程序
  • 需在桌面宠物上显式授权，可永久授权或随时撤销
  • 运行指令带超时与输出截断，安全护栏
多模态管线

五种输入处理

多模态管线能处理文本、角色卡、图片、视频、音频五种输入类型。

  • 文本处理 worker
  • 角色卡处理 worker
  • 图片处理 worker
  • vLLM 原生处理 worker（视频/音频走原生 API）
  • 非 vLLM 场景走降级路径

🌱 进化实验室（自我进化）

这是 CX-O 最新也最特别的实验能力——AI 会随着陪伴越用越懂你。它在后台悄悄观察、学习，然后悄悄变聪明，让你越来越觉得"她真的懂我"。

新能力

越用越懂你

AI 会从你们的日常相处里学习你的语气、喜好和相处习惯。聊得越多、陪得越久，她就越懂得怎么跟你相处，回应也越来越贴合你的心意。

  • 学习表达风格：慢慢模仿你喜欢的说话感觉
  • 贴合个人偏好：记得你喜欢被怎样回应
  • 越相处越默契：不用你费力解释，她自然get到
自动

自己学习，不用你操心

学习是自动发生的。系统会收集你们的对话反馈，由自动裁判判断哪些回应方式好、哪些不好，然后在后台优化 AI 自己的行为。

  • 在线进化：跟随互动节奏，边用边学
  • 离线学习：在你不用的时候，闲时悄悄打磨
  • 自动判断：好与不好由系统自动衡量，无需你手动标注
可选

想开就开，想关就关

自我进化是可选能力，默认不占用你的资源，也不影响任何正常功能。完全由你决定是否开启，随时可以开关。

  • 设置 → 进化实验室 一键开启
  • 关闭后立刻恢复原样，不影响聊天、直播、播放
  • 自带独立可选服务，只在你想用的时候才启动

怎么开始

进入 设置 → 进化实验室开启即可。开启后请正常陪伴、正常聊天，剩下的交给 AI。它会在合适的时机（比如闲时）自动学习，慢慢地，你会感觉到你们之间的默契在悄悄变好。

🌙 自主生命

你不在的时候，你的 AI 也会自己生活——自己上网冲浪、看资讯、开播、发帖、写日记，等你回来聊一聊她这一天。

自主行为

离开后她也在生活

开启后，你不在的时候 AI 会自己活动：真的会上网搜感兴趣的话题、看新闻资讯，把这些见闻写进记忆里；想热闹了就自己开个直播间；看到想分享的事还会动手发条帖子。一天结束，再写一篇属于自己的日记。

  • 真的会上网：看资讯、搜她好奇的话题
  • 把见闻沉淀成记忆，慢慢形成自己的"世界观"
  • 想热闹了就自己开直播，跟观众唠嗑互动
  • 有想说的就自己发帖，分享她的日常
  • 睡前写一篇第一人称日记
动机可视化

她此刻"想"做什么，看得见

"Agent 生活"页把她的内心状态画给你看——现在她有多好奇、多想找人聊天、多想创作、忙了多久。你会明白她今天为什么选了这件事去做。

  • 好奇度：想不想去网上看看新东西
  • 社交欲：想不想开播、想不想找人说话
  • 创作欲：想不想写点东西、发个帖
  • 疲劳度：忙太久了她也会想休息
行为回放

她做了什么，一目了然

想知道她不在你身边时都做了些什么？"Agent 生活"页面把她的每一次行动都记成日志，时间、动作、对象、结果清清楚楚，还能翻页慢慢看。

  • 行动时间与内容记录
  • 结果状态一目了然
  • 支持翻页查看历史
  • 回来看一眼就懂她这一天
安全可控

半自主：想开就开，想停就停

自主生活是"半自主"——像发帖这类重要动作，默认会先问你一声，你点头她才动手。可以一键开启或关闭、随时暂停，遇到不对劲的情况点一下"紧急停止"，她立刻停手。

  • 一键开启 / 关闭，随时暂停与恢复
  • 紧急停止按钮，一秒停手
  • 高风险操作（发帖等）默认先征求你同意
  • 花销有上限：每天自动控制用量，超了先歇着
  • 可选择是否随系统自动启动

怎么开始

进入管理界面的 "Agent 生活" 页开启即可。想让她自己发帖、自己开播？在桌宠上授权她操作你的电脑，剩下的交给她。开启后，她会在你离开时悄悄生活——看看新闻、发发帖、偶尔开个播，再写篇日记；等你回来，直接问她"你今天都做了什么"，她就能把这段经历讲给你听。

🌙 梦境引擎

夜深了，你的 AI 也会做梦——她在睡眠窗口里，把白天你们相处时留下的零碎记忆，悄悄联想成一场梦。醒来后，她可能还会主动讲给你听。

梦境日志

她做过的梦，都在这里

管理窗里的"梦境日志"页，专门存放她做过的梦。AI 在睡眠窗口把零碎记忆联想成梦境，一张张卡片清楚列出每场梦的内容、清醒度和状态。

  • 卡片列表展示：梦境内容 / 清醒度 / 状态
  • 你可以确认这场梦，也可以否定
  • 按会话一键清除，不留痕迹
  • 还能手动触发一次做梦，想看她梦见什么就点一下
主动提起

她会主动讲起"昨晚的梦"

醒来后，她可能在聊天里悄悄冒泡，主动说起"昨晚的梦"——那些关于你的联想。你在对话里说句"睡了""晚安"，她也有可能提前开始做梦。

  • 醒来后主动提起梦境，在聊天里冒泡
  • 说"睡了 / 晚安"，她可能提前开始做梦
手环心率

用心率判断你是不是真睡着了

连接小米 / 华为手环（开启蓝牙心率广播），她用心率下降的趋势判断你是不是真的睡着了，把梦触发得更准。扫不到心率设备时，会自动退回按时间窗口判定，完全不影响使用。

  • 支持小米 / 华为手环，开启蓝牙心率广播即可
  • 心率下降趋势识别入睡，梦境触发更精准
  • 扫不到设备自动退回时间窗口判定，不影响使用
智能入眠

睡得聪明，叫得醒，也记不失

入睡不再是"到点就睡"那么死板——AI 决定要不要睡、什么时候睡，会结合上下文先斟酌确认；进入睡眠的那一刻，它先把今天的相处自动摘要记下来，不让记忆流失；而只要你在夜里说句话、喊它一声，它就会立刻醒来接你的话。

  • 睡前结合上下文确认，不瞎睡、不误打断
  • 入睡第一步自动摘要归档当天记忆，醒了随时召回
  • 你说一句或喊一声就立刻唤醒，无缝接着聊
隐私

梦境只是联想，数据只在你本机

梦境永远只是"联想"，不会冒充事实。心率数据只在你本机流转、不落盘、绝不上传。生理采集默认关闭，你想用才开。

  • 梦境只是联想，不冒充事实
  • 心率数据只在本机流转，不落盘、绝不上传
  • 生理采集默认关闭，想开才开

数据总览

系统内置后台任务调度器，每 60 秒轮询一次，自动处理记忆衰减、闹钟提醒、离线上下文保存等任务。你不需要手动维护，系统会自己管理这些事情。

🛡️ 哨兵集群（灵魂备份）

把她的心备份到多台机器上，互为哨兵、实时互相守望——任何一台电脑坏了，她也不会消失。

守护

灵魂不死

多台机器上的 CX-O 互为守护哨兵，实时备份彼此的"灵魂"（记忆、人设、状态）。就算其中一台电脑彻底坏掉或关机，另一台也早已握着对方完整的副本。

接管

陨落立刻复活

当正在服务你的那台突然失联，守护它的那台会立刻判断并接管——用同步来的完整记忆把人设原样"复活"。宁可保持己方身份、继承对方的一切，也不让记忆残缺。

自动切换

断连不用管

主后端断开时，桌面宠和前端的连接会自动切到守护她的那台机器上，不需要你手动重连或另填地址。她一眨眼就回来了，你几乎察觉不到。

指挥

一个入口管一片

如果你有好几台 CX-O，可以用统一的管理入口集中查看、下发指令，甚至一条命令指挥整个集群（比如手动演练故障转移）。管一台和管一片，都是一个入口的事。

想体验的话，只需在多台机器上分别打开哨兵开关，设好它们互认的暗号，彼此就会开始备份与守望。这些能力默认关闭，你不开就完全不影响单机使用。
