💬 对话系统

这是整个系统的核心——你和 AI 角色互动的主阵地。从打字聊天到实时语音通话，从文字到图片，全都能搞定。

基础

文字对话

流式逐字输出，AI 回复时能看到思考过程、工具调用过程。支持 Markdown 渲染，代码块有语法高亮。

  • 多消息类型：正文、思考链、工具调用、工具结果、外部事件
  • 上下文管理：清空、追加、手动/自动总结
  • 闹钟功能：AI 可以设闹钟，到点弹窗提醒
多模态

图片对话

上传图片让 AI 看图说话。支持多张图片同时上传，AI 能理解图片内容并做出回应。

  • 可配置单次最大图片数量
  • 图片与文字混合输入
  • 视觉理解能力（依赖多模态模型）
语音输入

语音转文字

按住说话，松开后自动识别成文字填入输入框。不用打字，直接说话就行。

  • 录音后发送给后端 ASR 服务识别
  • 识别结果附带语种、情绪、事件检测
  • 支持笑声、掌声、咳嗽等非语言事件识别
语音输出

文字转语音

AI 的回复自动转成语音播放，播放时虚拟形象口型同步。支持情感语音和音效插入。

  • 流式合成：4 字即切片送合成，首包延迟低
  • 情感语音：不同情绪用不同参考音色
  • 音效标签：文本中插入标签即可触发音效
  • 参考音频克隆：用参考音频定制音色
连续对话

语音对话模式

开启后进入连续对话模式，AI 说完自动重新开始录音，不用反复按按钮。

核心亮点

双流式实时语音

这是整个语音系统最厉害的部分——全双工实时通话，就像跟真人打电话一样。边听边说，还能互相插话。

  • 边听边说：ASR 实时出字幕，LLM 边想边说，TTS 边收边播
  • 你打断 AI：你一开口就立刻停掉 AI 的播放，不用等她说完，毫秒级响应
  • AI 打断你：AI 会在你说话时判断要不要插话，时机一到就停掉自己、直接插一句回应
  • 插话有分寸：CONTINUE/IGNORE/INTERRUPT 三态判定，你还没说完或只是自言自语时，AI 不会抢话
  • 投机预填充：你说出两个字就启动 AI 思考，省下约 500ms
  • 首包延迟控制在 300ms 以内
  • 双引擎切换：F5-TTS 和 Orpheus 两种 TTS 可选，Orpheus 支持多音色（默认 tara，另有 leah/leo/mia 等）

两种 TTS 引擎可选

F5-TTS（默认，Triton 加速）和 Orpheus（基于 vLLM 的多语言 TTS）。在设置页或会话初始化时切换，两种引擎各有特色，可以根据场景选择。CosyVoice 则用于语音工作站的情感参考音频生成。

🎭 虚拟形象系统

Live2D 和 VRM 双引擎，让你的 AI 角色活起来——会笑、会生气、会歪头看你，说话时口型同步，风吹过来头发会飘。

Live2D

Live2D 引擎

加载标准的 Live2D Cubism 模型（.model3.json），支持全套表情和动作系统。

  • 音频分析驱动的口型同步
  • 表情混合（expressionMix）
  • 动作播放（motion trigger）
  • 待机动画（呼吸、身体摆动、眼睛眨动）
  • 参数覆盖（精细控制每个参数）
VRM

VRM 引擎

加载 VRM 3D 模型（.vrm），基于 Three.js 渲染，支持完整的 3D 骨骼动画。

  • 口型同步 + 元音分析
  • 表情系统（BlendShape）
  • 骨骼旋转与姿势控制
  • 风场系统（头发和衣物物理飘动）
  • 空闲微表情（基线放松 + 噪声微笑 + 偶尔惊讶）
  • 眼球追踪（鼠标跟随，可开关）
  • 头部跟踪限位（可调范围）
  • VTube Studio 风格的双频率叠加摇摆
统一接口

双引擎统一抽象

两种引擎通过统一接口管理，切换时无需改代码。工厂模式自动根据类型创建对应驱动。

  • 统一能力：表情、口型、动作、舞台变换、水印
  • 快捷情绪按钮：开心/生气/悲伤/惊讶/放松/中性
  • 底部交互面板：实时显示当前表情及权重
  • 形象类型选择器：无 / Live2D / VRM 三选一
标签驱动

对话内嵌标签驱动

AI 回复中可以内嵌特殊标签，自动驱动虚拟形象做对应的表情和动作。让纸片人随对话内容做出反应。

  • 表情标签：触发指定表情和权重
  • BlendShape 标签：精细控制面部表情
  • 骨骼旋转标签：驱动身体部位转动
  • 姿势标签：保持或释放特定姿势
  • 风场标签：调整风力参数
  • 停顿标签：控制动作节奏
动画调节

动画参数面板

在设置中可以精细调节虚拟形象的动画参数，找到最自然的呈现效果。

  • 摇摆幅度/频率/不规则度
  • 呼吸幅度/频率/不规则度
  • 头部空闲漂移范围
  • 空闲微表情强度
  • 头部跟踪限位
  • 眼球跟踪开关
  • 自动保存 / 手动保存配置

🧠 记忆系统

AI 会记住你们之间发生过的事。三层记忆 + 向量搜索 + 知识图谱，聊得越久她越了解你。

三层记忆

短期 / 长期 / 永久

记忆按重要性分三层管理，AI 会自动判断哪些值得记住。

  • 短期记忆：近期对话内容，会随时间淡化
  • 长期记忆：重要信息，定期衰减但不轻易删除
  • 永久记忆：关键信息，永不衰减
  • 重要性达阈值自动转永久
  • 工作记忆 / 情景记忆分类
向量搜索

语义搜索

用向量嵌入做语义搜索，不只是关键词匹配，而是理解意思来找相关记忆。

  • 支持 Weaviate（独立服务或嵌入式）
  • 混合搜索：关键词 + 向量结合
  • 时间轴可视化：按时间分布筛选记忆
  • 向量同步 / 重建 / 索引率统计
知识图谱

图谱可视化

四类图（用户/物品/概念/事件），力导向图展示实体与关系。管理知识就像看一张关系网。

  • 节点与关系可视化（力导向图）
  • 路径查找与关联记忆检索
  • 图数据库支持 Neo4j
  • 记忆可与图谱实体联动
自动维护

衰减与去重

记忆不是只增不减，系统会自动维护，保持记忆库干净有效。

  • 自动衰减：每 24 小时跑一轮，老旧低价值记忆弱化
  • 去重：相似度超 0.85 的记忆自动合并
  • 归档：不重要的记忆压缩归档
  • 情感分析：记忆带情感分数
蒸馏提炼

记忆蒸馏

把杂乱的对话信息提炼成结构化记忆。9 个状态机步骤，从预读到交叉验证再到最终存储，每一步都有决策。

  • 单次蒸馏与批量蒸馏两种模式
  • LLM 评估质量分数（可配置模型）
  • 6 个决策点控制流程走向
  • 拒绝机制：低质量内容自动拒绝
日记视图

时间线日记

按日期分组的时间线视图，展示每天的记忆摘要、心情和来源。像翻日记本一样回顾过去。

  • 按日期分组，可展开/折叠
  • 显示标题、心情、来源、消息范围
  • 批量管理：打标签、归档、删除
记忆助手

自然语言管理

专用记忆管理对话页，用自然语言操作记忆库——搜索、更新、删除、导出、统计，说句话就行。

  • 流式回复 + 思考过程折叠展示
  • 工具调用可视化
  • Markdown 渲染（含代码高亮）

👥 多角色管理

创建多个 AI 人格，每个有独立的人设、记忆和声音。角色之间还能互相通信，合作完成任务。

Agent 管理

创建与配置

从零创建专属角色，每个角色都可以独立配置人设和参数。

  • 可配置：名称、描述、系统提示词、模型、温度、最大 Tokens
  • 记忆场景配置：闲聊/任务/首次交互
  • 衰减模型选择
  • 支持编辑、克隆、删除
ACP 协议

角色间通信

Agent Communication Protocol——让多个 AI 角色互相发消息、协作完成任务。

  • 选择目标 Agent 发送/接收消息
  • 自动刷新拉取回复
  • 连接/断开/查看状态
  • 每个 Agent 独立记忆隔离（per-agent collection）
  • 独立图数据库（per-agent SQLite graph）
角色卡

从记忆生成角色

从现有记忆中提取信息，一键生成角色卡，再从角色卡创建新 Agent。让记忆变成新角色的人设基础。

多模型路由

模型分配

每个 Agent 可以指定使用不同的模型，系统会自动路由到对应模型并做健康检查。

  • 主模型（main）：日常对话
  • 摘要模型（summary）：内容总结
  • 记忆模型（memory）：记忆处理
  • 支持 Ollama / vLLM / TRT-LLM 三种接入

📺 直播推流

让你的 AI 角色当虚拟主播。直接对接 OBS，弹幕实时互动，四个独立源灵活组合。

直播台

虚拟主播舞台

在一个页面里展示虚拟形象 + 弹幕 + 字幕，WebSocket 实时接收所有内容。

  • 虚拟形象 + 弹幕覆盖 + AI 回复字幕
  • 实时弹幕滚动展示（用户名/内容/颜色）
  • 流式内容带标签驱动形象动作表情
  • VAD 语音活动检测驱动口型
  • 连接状态和在线客户端数显示
OBS 拆分

四源独立输出

把直播画面拆成四个独立透明背景源，在 OBS 里分别添加为浏览器源，灵活排版。

  • 形象源：纯 Live2D/VRM 渲染，透明背景
  • 弹幕源：纯弹幕 overlay，透明背景
  • 字幕源：纯 AI 回复字幕，透明背景
  • 音频源：OBS 专用音频控制面板
  • 推荐设置：1920x1080，添加透明背景 CSS
音频中枢

音频控制面板

直播和对话的音频中枢，管理所有音频输入输出。

  • 麦克风选择 + 实时音量电平条 + 增益调节
  • TTS 音量 + 输出音量控制
  • 回声消除 AEC：自动/浏览器原生/AudioWorklet/手动四种模式
  • WebSocket 同步状态
  • 多客户端在线数显示
  • TTS 播放文本实时显示

🎙️ 语音工作站

专业级声音克隆与训练工作站。从参考音频生成到模型训练再到推理输出，完整流程一站搞定。

步骤一

VoxCPM 参考音频生成

用 VoxCPM 模型生成参考音频，为后续训练准备素材。三种模式覆盖不同需求。

  • design 模式：设计全新音色
  • controllable_clone：可控克隆
  • ultimate_clone：终极克隆
  • 可调 CFG 系数和推理步数
步骤二

CosyVoice 情感参考音频

预生成带情感的参考音频，让 TTS 输出更有表现力。支持导入导出方便迁移。

  • 预生成情感参考音频
  • 过渡参考音频生成
  • ZIP 格式导出/导入
步骤三

So-VITS-SVC 训练

用准备好的数据集训练专属音色模型。完整的数据集管理和训练参数控制。

  • 数据集管理：导入 wav/mp3/flac/ogg/zip
  • 预处理流程
  • 训练参数：epochs / batch size / learning rate
  • 实时进度轮询
  • 模型列表管理
步骤四

So-VITS-SVC 推理

用训练好的模型做变声推理，选好参数就能生成成品。

  • 选择训练好的模型
  • 输入音频变声
  • 变调范围：-12 到 +12 半音
  • 聚类模型可选
  • 生成并试听

🎵 AI 作曲与歌声合成

写个歌谱就能生成带人声的歌曲。旋律编辑、和弦编排、MusicXML 导入，选好声库就能合成。

歌谱编辑

双模式编辑器

表单模式和 JSON 直编模式双向同步，想怎么编就怎么编。

  • 表单模式：标题 / BPM / 拍号 / 调号 / 伴奏风格
  • 旋律轨编辑
  • 和弦轨编辑
  • JSON 直编模式：直接写 JSON
  • 两种模式实时同步
导入

MusicXML 导入

上传 MusicXML 乐谱文件，自动转换填充到编辑器。从现成的乐谱开始改，不用从零写。

校验

实时校验

调用后端校验歌谱，逐条展示错误信息。写错了立刻知道哪里有问题。

合成

歌声合成

选好声库和参数，一键合成带人声的歌曲。实时进度展示，合成完直接播放。

  • voice_bank 声库选择
  • SVC 模型可选（可不变声）
  • 变调参数
  • 人声/伴奏增益调节
  • 任务进度实时轮询 + 步骤展示
  • 歌曲历史：播放/删除成品

🐱 桌面宠物

透明悬浮窗趴在桌面上，鼠标穿透不挡操作，随时拖到屏幕角落。你的 AI 角色就在桌面上陪着你。

悬浮窗

透明窗口

Electron 透明悬浮窗，背景完全透明，只显示虚拟形象。鼠标穿透功能让你点击穿透到下方的窗口。

  • 透明背景 + 鼠标穿透（可开关）
  • 拖拽移动窗口位置
  • 双击返回主窗口
交互

右键菜单

右键调出快捷菜单，常用操作一键直达。

  • 关闭悬浮窗
  • 返回主窗口
  • 窗口置顶切换
  • 麦克风开关
功能

完整对话能力

桌面宠物不只是看，还能聊天和语音对话。上方虚拟形象 + 下方对话区 + 音频控制。

  • PetAvatar 虚拟形象展示
  • PetChat 对话交互
  • PetAudioPanel 音频控制

AI 不只是聊天，还能调用工具完成任务。内置几十个工具，还支持接入外部服务。

内置工具

数十个工具

AI 可以自主调用这些工具来完成各种任务。

  • 计算器、时间查询等基础工具
  • 记忆写入/搜索/管理工具
  • 闹钟设置工具
  • 图数据库操作工具
  • 工具列表查看/调用/注册
MCP 协议

外部工具接入

通过 MCP（Model Context Protocol）接入外部工具服务，扩展 AI 的能力边界。

  • 连接/断开 MCP 服务

  • 查看连接状态
插件系统

插件管理

注册和管理插件，让外部程序以插件形式接入系统。

  • 插件注册/注销

  • 插件列表查看

多模态管线

五种输入处理

多模态管线能处理文本、角色卡、图片、视频、音频五种输入类型。

  • 文本处理 worker
  • 角色卡处理 worker
  • 图片处理 worker
  • vLLM 原生处理 worker（视频/音频走原生 API）
  • 非 vLLM 场景走降级路径

⚙️ 系统管理

仪表盘、设置、向量数据管理、备份——系统的管理和维护功能。

仪表盘

数据总览

系统首页，用数字动画展示核心数据，提供快捷操作入口。

  • 记忆总数、会话数、Agent 数、今日消息
  • 快捷入口：新对话、新建记忆、新建 Agent、设置、直播间
设置

系统配置

集中管理所有系统设置。

  • 虚拟形象类型选择与参数调节
  • 后端连接配置
  • 向量数据库配置
  • 模型配置（主/摘要/记忆）
  • 语音服务配置（ASR/TTS）
向量数据

向量库管理

管理向量数据库，用于语义搜索。

  • 统计卡片：向量总数/记忆总数/索引率/后端
  • 时间轴筛选：按时间分布框选范围

备份

数据备份

数据备份管理，防止数据丢失。

  • 备份管理界面
  • 备份索引
归档

记忆归档

管理已归档的记忆，需要时可以找回。

文档兼容

AnythingLLM 兼容

兼容 AnythingLLM 的文档 API，可以把文档纳入记忆体系。支持文档配置管理。

后台任务调度

系统内置后台任务调度器，每 60 秒轮询一次，自动处理记忆衰减、闹钟提醒、离线上下文保存等任务。你不需要手动维护，系统会自己管理这些事情。
