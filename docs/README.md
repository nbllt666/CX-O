## 项目特色速览

- 🗣️ **端到端语音对话** - ASR → LLM → TTS 全流程
- 🧠 **智能记忆系统** - 模拟人类遗忘曲线的记忆管理
- 🔗 **知识图谱** - 四大图库、语义节点存储
- 🤝 **ACP 协议** - Agent 互联、群组协同
- 🔧 **MCP 工具生态** - 标准化工具协议
- 📺 **弹幕系统** - B站/RDF 弹幕接入
