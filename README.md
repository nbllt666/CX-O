# CX-O

> 你的二次元 AI 伙伴，能聊天、能记忆、能说话、能直播、能唱歌。

CX-O 是一套面向二次元爱好者的 AI 人格化陪伴系统。它把虚拟形象、语音对话、记忆管理、直播推流、声音克隆、AI 作曲这些能力整合到一个桌面应用里，让你和纸片人老婆/老公的互动不再停留在打字聊天。

---

## 这个系统能做什么

**和虚拟形象实时语音对话** — 加载 Live2D 或 VRM 模型，开口说话就能跟 AI 角色聊天。AI 边想边说，你和它随时能互相插话，就像在跟真人打电话。回复内容还能驱动角色做表情、做动作，聊天的时候她会笑、会生气、会歪头看你。

**记住你们之间发生过什么** — 三层记忆系统（短期/长期/永久），AI 会自己判断哪些事值得记住。聊得越久，她越了解你。还带向量语义搜索和知识图谱，能从海量记忆里精准召回相关内容。

**多角色切换与协作** — 创建多个 AI 人格，每个有独立的人设、记忆和声音，还能给每个角色单独绑定一段参考音频，让它的声音跟别的不一样。角色之间还能通过 ACP 协议互相通信，让不同的 AI 伙伴合作完成任务。

**虚拟主播直播** — 直接对接 OBS，拆分成形象源、弹幕源、字幕源、音频源四个独立浏览器源。开个直播间，让你的 AI 角色当主播，实时念弹幕、回观众消息。

**声音克隆与训练** — 语音工作站提供从参考音频生成到 So-VITS-SVC 训练的完整流程。用你喜欢的声音素材训练专属音色，还能给 AI 角色用上。

**AI 作曲与歌声合成** — 写个歌谱就能生成带人声的歌曲。支持旋律编辑、和弦编排、MusicXML 导入，选好声库和变调参数就能合成成品。

**自我进化（可选）** — AI 会随着陪伴越用越懂你。它会在离线闲时悄悄总结你们的相处，学习你的语气和喜好，让自己变得更贴心。全程可选，想关随时关，不影响正常聊天、直播和播放。

**桌面宠物** — 透明悬浮窗趴在桌面上，鼠标穿透不挡操作，随时拖到屏幕角落。可以同时开好几只，各是不同角色、各说各话；右键还能调出菜单，随时开始对话。

**多桌宠与圆桌会议** — 桌面宠物想开几只开几只，每只各是不同角色、各有自己的声音。还能把几个角色拉进同一场"圆桌会议"，你坐主位，点名谁谁接话、或让它们按话题抢答，几个角色轮流跟你聊，像一群人围着你开会，谁说话一目了然。

**灵魂备份（多机哨兵）** — 把她的心备份到多台机器上，互为哨兵、实时互相守望。哪怕一台电脑坏了或关机，另一台会立刻顶上来接手，她照旧活着，记忆和个人都不丢。

## 快速上手

### 你需要准备什么

- 一张 NVIDIA 显卡（最低 16GB 显存，推荐 20GB 以上）
- Python 3.11 或更高版本
- Node.js 18 或更高版本
- Docker 和 Docker Compose（用于跑语音和推理服务）
- Ollama（用于跑对话大模型）

### 三步启动

**第一步：准备环境**

```powershell
# 在项目根目录运行，自动创建 Python 虚拟环境
.\create-env.bat

# 激活环境
call py311\Scripts\activate.bat
```

**第二步：拉模型**

```powershell
# 对话模型（主模型 + 向量嵌入模型）
ollama pull qwen3-vl:8b
ollama pull nomic-embed-text

# 语音相关模型
python download_voxcpm2.py
python download_voxcpm_support.py
```

**第三步：启动服务**

```powershell
# 1. 启动后端（端口 8000）
cd CX-O-SERVER
.\start.bat

# 2. 启动前端（端口 3100）
cd APP-Frontend
.\start.bat browser
```

浏览器打开 `http://localhost:3100`，第一次会引导你确认后端连接，连上就能开始用了。

> 语音对话功能还需要额外启动 ASR 和 TTS 服务，具体见部署文档。

| 功能 | 说明 |
|------|------|
| 实时语音对话 | 全双工通话，边听边说，双向互相插话，延迟可控在 300ms 内 |

| 声音克隆 | VoxCPM 音色设计与情感参考 + So-VITS-SVC 训练推理 |
| AI 作曲 | 歌谱编辑 + MusicXML 导入 + 声库选择 + 歌声合成 |
| 桌面宠物 | 多只悬浮窗同时开，鼠标穿透，拖拽移动，右键菜单，每只各自一个角色 |
| 圆桌会议 | 把几个角色拉进同一场语音会议，你点名、它们按话题轮流/抢答跟你聊，各用各的声音 |
| 自我进化 / 进化实验室 | AI 越用越懂你，在离线闲时自动学习你的偏好，可选开启 |
| 工具系统 | 数十个内置工具 + MCP 协议接入外部工具 + 插件系统（支持直连、前端转接、后端嵌入式三种接线方式） |
| 自主生命 | 你离开后 AI 也会自己生活——看资讯、写日记、沉淀经历、记录它做过的事，你回来随时可以聊天召回 |
| 梦境引擎 | 夜深了她会做梦——把白天相处的零碎记忆联想成一场梦，醒来讲给你听，你确认才算数；入睡时会聪明地判断、睡前先自动摘要、你叫他随时醒来 |
| 屏幕感知 | 可选开启后，AI 能"看见"你的屏幕或摄像头画面，聊天时据此回应你正在做的事，还会记住你刚经历的过程 |
| 电脑控制 | 让 AI 帮你操作电脑（看屏幕、按键、运行程序），需在桌面宠物上显式授权 |
| 哨兵集群 | 多台机器上的 CX-O 互为哨兵、实时备份记忆与人格；任一节点陨落由他节点接管复活，她不死；后端断开时前端自动切换到守护她的那台 |
| CX-A 管理面 | 一个入口统一管理整套 CX-O（自描述、强认证、可编排），还能一个命令指挥整个哨兵集群 |

「屏幕感知」也升级了：她不止"看见"当下，还能记住你经历的过程——你玩了两小时游戏、debug 卡住又解决，这些都会沉淀成她的记忆，改天聊起还能回忆。现在分两种模式：省资源的「看图模式」会自动调节节奏（画面动得勤就看得勤、静止就放慢）；记录过程的「录像模式」默认关闭，需要时再单独打开。

桌宠方面也讲两句新的：现在**桌宠能一口气开好几只**了，每只各自绑不同的角色、各有各的声音，互不打扰。每个角色还能在管理页里**单独绑定一段参考音频**，让它的嗓音跟别的不一样。想更热闹的话，把几个角色拉进同一场**「圆桌会议」**，你坐主位，点名谁谁接话，或让它们按话题抢答，几个角色轮流跟你聊，谁在说话一眼就看得出来。

## 常见问题

**启动后端报错连不上 Ollama？**
先确认 Ollama 服务在跑（`ollama serve`），默认地址 `http://localhost:11434`。模型没拉全也会报错，确保 `qwen3-vl:8b` 和 `nomic-embed-text` 都拉好了。

**语音对话没声音？**
语音对话依赖 ASR 和 TTS 两个独立服务。默认配置走远程模式，需要用 Docker 启动 `asr-sensevoice` 和 TTS 服务。具体端口和启动方式见部署文档。

**Live2D 模型怎么加载？**
在设置页面选择形象类型为 Live2D，然后上传 `.model3.json` 文件。VRM 模型同理，上传 `.vrm` 文件即可。

**显存不够怎么办？**
单卡 16GB 可以跑基础对话，但语音相关服务比较吃显存。可以关掉不用的服务，或按需只保留对话所需的 TTS 引擎来减轻压力。
